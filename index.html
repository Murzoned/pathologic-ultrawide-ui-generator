Pathologic Classic HD — Custom UI Generatorv1.0

Generate native UI layouts and loading screens for any widescreen or ultrawide resolution (21:9, 32:9, 16:10, 48:9) directly from your original game archives. Everything runs locally in your browser.

1. Target Resolution
Standard resolutions up to 1920×1200 are already built into the game. Enter a higher resolution (e.g. 2560×1440, 3440×1440, 5120×1440).
2. Layout Options & Game Archives

Select UI.vfs and Textures.vfs from your game's data/ folder:

3. Installation
  1. Extract the downloaded ZIP archive into your game's data/ directory so that UI/ and Textures/ sit alongside UI.vfs and Textures.vfs.
  2. Open data/config.ini and set your resolution under [Video]: 
    XRes = 5120
YRes = 1440
  3. Launch the game. To uninstall, delete the extracted data/UI/ and data/Textures/ folders (or only the generated files if you have other custom files in those folders).
